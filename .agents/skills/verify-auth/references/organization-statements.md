# B2 component expectations outside this upkeep

The Fleet access B2 design is owner-held and is not shipped in this repository. The expected behavior stated here is the authoritative public statement for this supplementary scope. See the [public sign-in core contract](../../../../packages/sign-in-core/README.md) for the shipped boundary.

B2 stamp/revision tests remain in their existing permanent files. This B1 user-flow driver does not claim stamp renewal, Central CAS/ACK durability, real Central restart or hosted acceptance. No receipt-checking wrapper command is supported after the hard cutover. Add a scoped journey script and real-target coverage before advertising these as an operable user-flow recipe.
